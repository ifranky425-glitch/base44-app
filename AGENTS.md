# Base44 Dev Environment

## Project Overview
Vite + React app using `@base44/sdk` and `@base44/vite-plugin`. The app is a
"Rebridge" reflections platform with auth pages (Login, Register, Forgot/Reset
Password) and a Home page for logging reflection entries.

## Setup
```sh
docker compose -f docker-compose.base44.yml up -d --build
```
The compose runs `node:22-slim`, bind-mounts the repo, runs `npm install` on
startup, then starts `vite dev` on port 5173 (mapped to host port 3000).

## Key Configuration
- `MODAL_SANDBOX_ID=1` is passed to the container so the `@base44/vite-plugin`
  enters sandbox mode (binds 0.0.0.0:5173, allows all hosts, enables file
  polling for HMR in containers).
- No external secrets are required for the dev server to start. The app's API
  calls will fail with "app not deployed" until the app is published and
  `VITE_BASE44_APP_ID` / `VITE_BASE44_APP_BASE_URL` are configured.

   `index.html` with `<div id="root">` and `<script type="module" src="/src/main.jsx">`.

introduced by the automated sync commit — fixed to `${entry.aiAnalysis}`.
